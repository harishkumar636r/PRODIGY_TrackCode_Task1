# Interactive Navigation Menu

This project demonstrates an **interactive navigation menu** for a website that enhances user experience and usability. The navigation bar remains fixed at the top and responds dynamically to user actions:

- Changes background color when scrolling
- Hover effects on menu links
- Smooth scrolling to sections
- Fully responsive layout

## Built With
- HTML
- CSS
- JavaScript

## Sections
- Home
- About
- Topic
- Services
- Skills
- Contact
